
Our goal is to provide a seamless and efficient way to learn and improve your language skills. 
We aim to offer a wide range of features and functionalities that cater to different learning styles and preferences.

## features

- **Stream Rephrase**: Rephrase text in real-time using AI models.
- **Translation**: Translate text between multiple languages.
- **Grammar Correction**: Correct grammar and spelling errors.
- **Save Chat history**: Save chat history for future reference.
- **Analysis**: Analyze text for sentiment, tone, and readability.

## Support (local llm)

- **Ollama**: Use Ollama to run local models.
